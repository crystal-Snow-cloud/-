# MFC 通讯录管理系统（Trie树拼音前缀检索）
基于MFC对话框开发的通讯录管理桌面程序，使用**Trie字典树**实现联系人拼音前缀检索，支持大批量联系人导入与管理。
> 当前版本：基础功能可用，部分按钮功能暂未实现。

## 📦 项目结构
PhoneBook/
├── data/                   # 汉字转拼音字典文件夹（运行必需）
├── res/                    # MFC资源文件
├── x64/                    # 编译输出目录
├── Contact.h / Contact.cpp # 联系人实体类
├── Trie.h / Trie.cpp       # Trie字典树实现
├── PinyinConverter.h / PinyinConverter.cpp # 汉字转拼音工具类
├── PhoneBookDlg.h / PhoneBookDlg.cpp # MFC对话框主逻辑
├── PhoneBook.rc            # UI界面资源
└── PhoneBook.vcxproj       # VS2022项目文件
## 🛠️ 编译与运行环境
- IDE：Visual Studio 2022
- 框架：MFC（C++）
- 平台：x64
> ⚠️ 重要：程序运行依赖`data`拼音字典文件夹，调试时请在项目属性-调试中设置工作目录为`$(ProjectDir)`，保证程序可以加载拼音字典。

## 🚀 运行步骤
1. 使用VS2022打开`PhoneBook.vcxproj`
2. 项目属性 → 调试 → 工作目录填写：`$(ProjectDir)`
3. 生成解决方案，F5启动调试
4. 导入通讯录文本文件，即可加载联系人并使用拼音前缀检索

## 📝 说明
1. 拼音前缀查询依赖`data`目录下的拼音字典文件，缺失字典会导致汉字转拼音失效，Trie树无法插入联系人。
2. 标记为**待实现**的按钮仅保留UI界面，内部逻辑暂未开发，点击无效果。
3. 支持大批量联系人导入（测试30000条数据），基于Trie树优化前缀查询速度。
